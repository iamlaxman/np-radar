Our Mission

To make domain intelligence accessible to everyone in Nepal. Before NP Radar, checking WHOIS for .np domains meant navigating outdated portals or using global tools that didn't understand Nepal's unique domain ecosystem. We changed that.

Our Story

NP Radar was born out of frustration. As a Nepali developer and domain owner, I found myself constantly switching between multiple tools just to get basic information about a domain:

  • Mercantile's WHOIS portal for .np registration data — slow and clunky
  • External DNS tools for record checking
  • SSL checker websites for certificate validation
  • Multiple geolocation services to figure out hosting providers
  • And absolutely no tool that could tell me which Nepali ISP was hosting a domain

The idea was simple: what if there was one tool that did all of this, specifically designed for Nepal's domain ecosystem? A tool that understood .np domains, knew about Worldlink and Vianet and Subisu, and provided everything a Nepali developer or researcher needed in one place.

In 2025, that idea became NP Radar — Nepal's first dedicated domain intelligence platform.

What Makes NP Radar Different

🇳🇵 Nepal-First Design

NP Radar is built specifically for Nepal's domain ecosystem. We understand .np TLDs, Nepali ISPs, Mercantile's WHOIS system, and the unique challenges of Nepal's internet infrastructure. No global tool has this level of local intelligence.

🔍 Comprehensive Intelligence

We don't just do WHOIS. NP Radar aggregates 14+ data points per lookup — WHOIS records, DNS records (A, AAAA, MX, NS, TXT, CNAME, SOA, CAA), SSL certificate analysis, DNSSEC validation, IP geolocation, ISP detection, security header analysis, and technology stack fingerprinting — all in one place.

💰 100% Free, No Strings Attached

NP Radar is and will remain completely free. No accounts, no credit cards, no usage limits, no paywalls. We believe domain intelligence should be a public resource, not a commercial product locked behind subscriptions.

🛡️ Privacy-First

We don't collect personal data, don't use tracking cookies, and don't store your search history. NP Radar is designed to be stateless — domain lookups are processed in real-time and not permanently stored. Read our privacy policy →

⚡ Fast & Lightweight

No bloated frameworks, no heavy JavaScript bundles. NP Radar is built with vanilla HTML, CSS, and JavaScript with a lightweight Node.js backend. The result? Fast load times and smooth performance even on slower connections.

Technology Stack

NP Radar is built with modern, reliable technologies chosen for performance and simplicity:

Backend

Node.js with Express.js — handles WHOIS queries (TCP + web scraping), DNS resolution (native module), SSL certificate checks, and API routing.

Node.js Express.js node-cache

Frontend

Vanilla HTML/CSS/JavaScript with Tailwind CSS — no heavy frameworks, fast loading, responsive design, and smooth animations.

HTML5 Tailwind CSS JavaScript

Data Sources

WHOIS via register.com.np (web scraping), DNS via native resolver, SSL via crt.sh, geo via ip-api.com.

register.com.np crt.sh ip-api.com

Hosting

Deployed on standard VPS infrastructure with Node.js runtime. Stateless architecture — no database, minimal resource usage.

VPS Stateless
